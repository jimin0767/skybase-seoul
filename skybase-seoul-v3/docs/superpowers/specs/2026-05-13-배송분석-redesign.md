## 1. 목표

`index.html`의 배송 분석 탭(`#tab-analysis`)을 GitHub / Bloomberg 스타일의 "Premium Analytics" 테마로 재구성한다. 데이터는 변경하지 않고, 시각 언어만 교체한다.

---

## 2. 디자인 언어

### 색상 팔레트 (CSS 변수)

| 변수 | 값 | 용도 |
|---|---|---|
| `--bg` | `#0d1117` | 페이지 배경 |
| `--panel` | `#161b22` | 카드/패널 배경 |
| `--border` | `#21262d` | 테두리 |
| `--text` | `#e6edf3` | 본문 텍스트 |
| `--muted` | `#8b949e` | 레이블/부제 |
| `--blue` | `#58a6ff` | 시간 관련 강조 |
| `--green` | `#3fb950` | 긍정 지표, 탄소 |
| `--orange` | `#f0883e` | 비용 관련 강조 |
| `--red` | `#f85149` | 부정 지표 |
| `--purple` | `#bc8cff` | 기후 관련 강조 |

### 카드 스타일
- 배경: `var(--panel)` (`#161b22`)
- 테두리: `1px solid var(--border)` (좌·우·하), 상단에만 `3px solid var(--accent)` 포인트 바
- 모서리: `border-radius: 0 0 8px 8px` (상단 포인트 바와 자연스럽게 연결)
- 카드 제목: `::before` 3px 세로 바 + 대문자 + `letter-spacing: 0.08em`

### 타이포그래피
- KPI 레이블: `font-size: 11px`, `text-transform: uppercase`, `letter-spacing: 0.08em`, `color: var(--muted)`
- KPI 값: `font-size: 28px`, `font-weight: 700`, `letter-spacing: -0.03em`
- 섹션 구분선: 행 레이블 + `::after { flex:1; height:1px; background:var(--border) }`

## 5. 구현 범위

- **변경:** `#tab-analysis` 섹션의 HTML 구조, CSS 클래스, 인라인 스타일
- **유지:** 기존 Chart.js 차트 인스턴스 및 데이터 바인딩 로직 (JS 함수 그대로)
- **추가:** `--bg`, `--panel`, `--border` 등 CSS 변수 블록 (`:root` 또는 `#tab-analysis` 범위)
- **제거:** 기존 배송 분석 탭의 옅은 배경·밝은 텍스트 계열 스타일

---

## 6. 완료 기준

1. `#tab-analysis` 탭 전환 시 Premium Analytics 테마가 정확히 표시된다.
2. `#tab-optimization` 거점 최적화 탭에는 시각적 변경이 없다.
3. 기존 차트(레이더·라인·바)가 동일 데이터로 정상 렌더링된다.
4. 모든 텍스트가 한국어이며 띄어쓰기 오류가 없다.
5. 필터(자치구·평일/주말·시간대·월)의 기능이 정상 동작한다.
